Linux Keyboard Shortcuts

Super

  • Open the Activities overview.

Super + A

  • Show installed applications.

Super + L

  • Lock the screen.

Super + V

  • Open the notification list on supported GNOME versions.

Ctrl + Alt + T

  • Open the terminal on standard Ubuntu desktop installations.



Alt + F4

  • Close the current window.

Alt + F10

  • Maximize or restore a window.

Super + Left

  • Tile the active window to the left.

Super + Right

  • Tile the active window to the right.

Super + H

  • Hide or minimize the active window on supported configurations.



Ctrl + A

  • Select all in many applications.

Ctrl + C

  • Copy selected content in graphical applications.

Ctrl + V

  • Paste copied content in graphical applications.

Ctrl + X

  • Cut selected content in graphical applications.

Ctrl + Z

  • Undo the last action in applications that support it.

Ctrl + S

  • Save the current document in applications that support it.



Ctrl + Shift + C

  • Copy selected text from the terminal.

Ctrl + Shift + V

  • Paste text into the terminal.

Ctrl + C

  • Interrupt a running foreground command in the terminal.

Ctrl + L

  • Clear the visible terminal screen in common shell configurations.
