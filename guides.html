Linux for Beginners

Welcome to Linux for Beginners

Welcome to the TuxGuide Linux learning center!

This section is designed to help beginners understand Linux, learn how Ubuntu works, and become more

confident using their computers. Whether you are completely new to Linux or just want to improve your

skills, these guides will help you understand the basics step by step.

Each guide explains important concepts, provides examples, and introduces useful tools that you can use

on your own Ubuntu computer.

Important: Always read instructions carefully before changing system settings or running commands.


1. What Is Linux?

What is Linux?

Linux is an operating system kernel that helps software communicate with computer hardware.

An operating system manages important parts of a computer, including memory, applications, files,

and connected devices. It provides the environment that allows users to interact with their computers.

Linux is used in desktop computers, servers, supercomputers, embedded devices, and many other systems.


What is Ubuntu?

Ubuntu is a Linux distribution. A Linux distribution combines the Linux kernel with software, system

tools, applications, and other components to create a complete operating system.

Ubuntu provides a graphical desktop that lets you open applications, manage files, connect to networks,

change settings, and perform everyday computer tasks.


Why do people use Linux?

- Linux is available in many free and open-source distributions.

- It can be customized to suit different needs and preferences.

- It is widely used for programming and software development.

- It powers many internet servers and computing systems.

- It provides powerful command-line tools for managing a computer.

- It supports a wide range of hardware and software, depending on the distribution.


What is a Linux distribution?

A Linux distribution is a complete operating system built around the Linux kernel.

Different distributions include different software, desktop environments, package managers, and default

settings. Examples include Ubuntu, Debian, Fedora, Linux Mint, and Arch Linux.

Although these distributions share many Linux concepts, some commands and system administration

procedures can differ between them.


What is open-source software?

Open-source software makes its source code available under a licence that allows people to use, study,

modify, and redistribute it according to the licence's terms.

Many Linux projects are open source, allowing developers around the world to contribute improvements,

fix bugs, and help maintain the software.


What should you learn first?

If you are new to Linux, start by learning how to navigate the Ubuntu desktop, manage files and folders,

install applications, and use a few basic terminal commands.

You do not need to understand every technical detail immediately. You can learn more as you become

comfortable using the system.


2. Understanding the Ubuntu Desktop

What is the Ubuntu desktop?

The Ubuntu desktop is the graphical environment that allows you to interact with your computer using

windows, menus, icons, buttons, and other visual elements.

Instead of typing commands for every task, you can use your mouse or keyboard to open applications,

browse files, change settings, and perform everyday activities.


The top bar

The top bar appears along the top of the standard Ubuntu desktop.

Depending on your Ubuntu version and configuration, it can provide access to the date, time, calendar,

notifications, sound controls, network settings, power options, and other system information.

You can use the system menu to access common settings and check the status of your computer.


The Activities overview

The Activities overview helps you find applications and switch between open windows.

You can usually open it by pressing the Super key, which is often the key with the Windows logo.

From the overview, you can search for installed applications, view open windows, and access workspaces.


The application launcher

The application launcher gives you access to the applications installed on your computer.

You can use it to open programs such as Firefox, Files, Settings, and Terminal.

Depending on your Ubuntu version, you can find the application grid through the Activities overview

or the application launcher icon.


The file manager

The Ubuntu file manager allows you to browse, open, copy, move, rename, and organize files and folders.

You can use it to access locations such as Documents, Downloads, Pictures, Videos, and external drives.

Take care when moving or deleting files, especially if you do not know what they are used for.


System Settings

System Settings allows you to configure your computer.

You can use it to change the appearance, adjust the display, manage sound, configure Wi-Fi, add printers,

change keyboard shortcuts, manage accessibility options, and adjust other system settings.

The available options may vary depending on your Ubuntu release and hardware.


Switching between applications

When several applications are open, you can switch between them without closing them.

On the standard Ubuntu desktop, Alt + Tab usually lets you move between open applications.

You can also select an application's window directly from the Activities overview.


What are workspaces?

Workspaces let you organize open windows into separate working areas.

For example, you could use one workspace for browsing the internet and another for coding or studying.

Workspaces can help keep your desktop organized when you have several applications open.


Helpful tip

Take some time to explore the desktop and learn where the main tools are located.

You can safely explore most ordinary desktop settings without using the terminal.

If your desktop looks different from the examples in a guide, check which Ubuntu version and desktop

environment you are using. The appearance and available features may differ.


3. Understanding Files and Folders

What are files and folders?

A file stores information, such as a document, photograph, video, application configuration, or text file.

A folder is a location used to organize files and other folders.

Keeping files organized makes them easier to find and helps prevent important documents from being lost.


What is the Linux filesystem?

Linux organizes files in a hierarchical structure that begins at a location called the root directory.

The root directory is represented by a forward slash (/).

Other directories and files are organized beneath it. This structure includes personal files, system

configuration, installed software, temporary data, and other information.


Important filesystem locations

/ - The root directory, which is the starting point of the filesystem.

/home - Contains the home directories of regular users.

/home/username - A user's personal home directory. The actual username will differ.

/etc - Contains many system-wide configuration files.

/usr - Contains many programs, libraries, and shared resources.

/var - Contains variable data, including many logs and caches.

/tmp - Used for temporary files.


Your home directory

Your home directory is the main location for your personal files and settings.

It commonly contains folders such as Documents, Downloads, Music, Pictures, Public, and Videos.

You can create additional folders to organize your schoolwork, projects, photographs, and other files.


What is a file path?

A file path describes the location of a file or folder in the filesystem.

For example, /home/alex/Documents/report.txt describes a file named report.txt inside a Documents

folder belonging to a user whose username is alex.

The username and file names in this example are illustrative. Your own path will depend on your system.


Absolute paths and relative paths

An absolute path describes a location starting from the root directory.

For example, /home/alex/Documents is an absolute path.

A relative path describes a location in relation to the directory you are currently working in.

For example, if your current directory is /home/alex, the relative path Documents refers to the

Documents folder inside that directory.


Hidden files

In Linux, filenames that begin with a dot are generally treated as hidden files.

These files often contain settings or configuration information for applications and the desktop.

For example, a hidden configuration file may store your personal preferences for an application.

Hidden does not mean unimportant. Avoid deleting hidden files unless you understand their purpose.


Organizing your files

Create folders with clear names so you can find your files easily.

For example, you might create separate folders for schoolwork, programming projects, photographs, and

documents. You can also use meaningful filenames to make files easier to recognize later.


Helpful tip

When learning Linux, experiment with your own files and folders rather than changing system files.

Never delete or move unfamiliar files from directories such as /etc, /usr, or /var.

Changing important system files can affect Ubuntu and the applications installed on your computer.


4. Getting Started With the Terminal

What is the terminal?

The terminal is an application that lets you interact with your computer through text commands.

Instead of clicking buttons and menus for every task, you can type a command and press Enter to run it.

The terminal is useful for navigating files, managing software, checking system information, and learning

how Linux works.


What is a shell?

A shell is a program that reads and interprets commands.

Ubuntu commonly uses Bash as a shell, although other shells are available.

The terminal provides the interface where you can interact with a shell.


How to open the terminal

On a standard Ubuntu desktop, you can usually open the terminal by pressing Ctrl + Alt + T.

You can also search for Terminal in the Activities overview or application launcher.

The shortcut may differ if your keyboard settings have been changed or you are using another desktop environment.


Understanding a command

A command tells the computer to perform a particular task.

Some commands display information, while others create files, install software, or change system settings.

After typing a command, press Enter to run it.

Commands often include options or arguments that change how they work.


Useful beginner commands

pwd - Displays the directory you are currently working in.

ls - Lists files and directories in the current directory.

cd - Changes the current directory.

mkdir - Creates a directory.

touch - Creates an empty file if it does not exist, or updates a file's timestamp.

cp - Copies files or directories.

mv - Moves or renames files and directories.

cat - Displays the contents of a file in the terminal.

man - Opens the manual page for a command.


Understanding pwd

The pwd command means "print working directory."

It displays the full path of the directory you are currently using.

This is useful when you are unsure of your current location in the filesystem.


Understanding ls

The ls command lists the files and directories in a location.

It helps you see what is inside the current directory without opening the file manager.

You can use it as you navigate through your folders.


Understanding cd

The cd command means "change directory."

It lets you move from one directory to another.

For example, changing to your Documents folder lets you work with files stored there.

Typing cd without a directory will usually take you back to your home directory in a standard shell.


Understanding mkdir and touch

The mkdir command creates a new directory, while touch can create an empty file if the file does not exist.

These commands are useful when organizing projects or creating files to practice with.

For example, you could create a practice folder and use it to learn basic file operations.


Understanding cp and mv

The cp command copies files or directories, while mv moves or renames them.

Be careful when using these commands because the result depends on the paths and arguments you provide.

Practice with unimportant sample files before using them on important documents.


Understanding cat and man

The cat command can display the contents of a text file in the terminal.

The man command opens a manual page that explains a command and its available options.

Manual pages are useful when you want to understand a command instead of relying on an unfamiliar example.


Common terminal mistakes

- Typing a command incorrectly.

- Using the wrong file or directory path.

- Forgetting that Linux filenames are usually case-sensitive.

- Copying a command without understanding what it does.

- Running a command with administrator privileges when they are not needed.


When should you be careful?

Some terminal commands can permanently delete data, change important settings, or affect the entire system.

Before running a command, make sure you understand its purpose and the files or settings it will affect.

Do not copy and paste commands from unfamiliar websites simply because someone says they will fix a problem.


Helpful tip

Start with commands that display information or work with harmless practice files.

Once you understand the basics, you can gradually learn more advanced commands and tools.

For more information, consult the official Ubuntu command-line tutorial and the relevant command manual pages.


5. Installing Software on Ubuntu

What is software installation?

Software installation is the process of adding an application or program to your computer so that you can use it.

Ubuntu provides several ways to install applications, depending on the software and its publisher.

Choosing a trustworthy source helps reduce the risk of installing unwanted or harmful software.


Using the App Center

The App Center provides a graphical way to browse and install supported applications.

You can search for an application, review the available information, and follow the installation instructions.

Depending on the application, the publisher and installation format may differ.


What is APT?

APT is a package management tool used by Ubuntu to install, update, and manage software packages.

It can obtain software from configured package repositories and handle many required dependencies.

Package repositories are collections of software packages maintained by Ubuntu or other software providers.


What does apt update do?

The apt update command refreshes the information Ubuntu uses to learn which packages are available

from its configured repositories.

It does not, by itself, upgrade all installed applications.

This distinction is useful when learning how Ubuntu's package management system works.


What does apt upgrade do?

The apt upgrade command installs available upgrades for installed packages when their dependencies allow it.

These upgrades can include security fixes, bug fixes, and other software improvements.

Review the proposed changes before confirming an upgrade, especially if Ubuntu indicates that important

packages will be changed or removed.


What are DEB packages?

DEB is a software package format commonly used by Debian-based distributions, including Ubuntu.

Some software publishers provide DEB packages for manual installation.

Before installing one, check that it is intended for your Ubuntu version and computer architecture.

Obtain packages from the official publisher or another source you trust.


What are Snap packages?

Snap is a software packaging and distribution system used on Ubuntu and other Linux distributions.

Snap applications are distributed as packages that include many of the components needed to run them.

The software may also receive updates through the Snap system.

Check the application's publisher and permissions information before installing it.


Why do applications have dependencies?

A dependency is a component that software requires in order to work correctly.

An application may depend on libraries, tools, or other packages already available on the system.

Package managers help identify and install required dependencies, although installation problems can sometimes occur.


How to choose trustworthy software

- Prefer Ubuntu's official software sources or the application's official publisher.

- Check the publisher's identity before downloading or installing software.

- Read the application's description and available documentation.

- Check whether the software supports your Ubuntu version.

- Avoid unfamiliar scripts or commands that request administrator privileges without explaining why.


Helpful tip

For everyday applications, begin with Ubuntu's App Center when a suitable version is available.

If you need to use the terminal to manage software, make sure you understand the command and review the

changes Ubuntu proposes before allowing the installation or upgrade to continue.


6. Understanding sudo

What is sudo?

sudo is a Linux command that allows an authorized user to run another command with elevated privileges.

These privileges are sometimes needed to perform administrative tasks, such as installing system software

or changing certain system settings.

On a typical Ubuntu installation, an authorized administrator may use sudo to perform these tasks.


Why does Linux use administrator privileges?

Operating systems use permissions to control which users can access or change files and settings.

Ordinary applications and users do not need full access to every part of the system.

Separating ordinary tasks from administrative tasks helps prevent accidental changes and limits the impact

of some security problems.


When is sudo used?

sudo may be required when installing certain system packages, changing protected configuration files,

or performing other administrative tasks.

Many everyday activities, such as browsing the internet, writing documents, and organizing personal files,

do not require administrator privileges.


Why should you be careful with sudo?

Commands run with elevated privileges can make changes that affect the whole computer.

An incorrect command may alter important system files, remove software, change permissions, or cause

Ubuntu to stop working correctly.

For this reason, you should understand what a command does before running it with sudo.


What happens when you enter your password?

When sudo requests authentication, you may need to enter your account password.

The terminal may not display characters, dots, or asterisks as you type. This is normal behavior in many

terminal configurations. Carefully type your password and press Enter.

Never share your password with another person or enter it into an untrusted website or script.


Common sudo mistakes

- Using sudo for commands that do not need administrative privileges.

- Running an unfamiliar command without understanding what it changes.

- Copying a command from an untrusted website and executing it as an administrator.

- Changing the permissions of system files without knowing the consequences.

- Assuming that a command is safe simply because it begins with sudo.


How to use sudo responsibly

Read a command carefully before you run it.

Check what the command will change and whether it is appropriate for your version of Ubuntu.

Prefer official documentation when learning administrative tasks.

If you are uncertain about a command, research it before running it with elevated privileges.


Helpful tip

Think of sudo as a tool for specific administrative tasks, not something to add automatically to every command.

Using normal user permissions whenever possible helps reduce the risk of accidental system changes.


7. Linux Users and Permissions

What are users and groups?

Linux supports multiple user accounts on the same computer.

Each user has an identity that helps the system determine which files and resources they can access.

Groups allow several users to share certain permissions.

This system helps keep personal files separate and controls access to shared resources.


What is file ownership?

Files and directories usually have an owner and an associated group.

The owner and group help determine who can read, change, or execute the file.

For example, a document in your home directory is commonly owned by your user account.

System files may be owned by administrative accounts because they control important parts of Ubuntu.


What are file permissions?

Linux permissions determine what users can do with files and directories.

The three basic permission types are read, write, and execute.

Read permission allows information to be viewed. Write permission allows changes to be made.

Execute permission allows a file to be run as a program or script when appropriate.

For directories, these permissions have related meanings involving listing, creating, and accessing entries.


Understanding read, write, and execute

Read: Allows the contents of a file to be viewed.

Write: Allows the contents of a file to be changed.

Execute: Allows a file to be run as a program or script when it is executable.

The actual result also depends on the file type and the permissions of the directory containing it.


What does chmod do?

The chmod command changes file or directory permissions.

It can be useful when a script needs permission to run or when access to a file must be adjusted.

However, incorrect permissions can prevent applications from working or expose files to unwanted access.


What does chown do?

The chown command changes the owner or group associated with a file or directory.

It is an administrative tool that should be used carefully.

Changing ownership of system files or large parts of the filesystem can cause serious problems.


Why do I sometimes get a permission denied message?

A permission denied message means that your current account or process does not have the access required

to perform an action.

This may be normal behavior when you attempt to access a protected system file or a resource belonging

to another user.

Do not automatically use sudo to bypass every permission error. First determine whether the action is

appropriate and why access is restricted.


How to manage permissions safely

Use the file manager's permission options when they provide the settings you need.

Before changing permissions in the terminal, understand the file, its owner, and the purpose of the change.

Make changes only to files you own or are authorized to manage.

Avoid applying broad permission changes to system directories.


Helpful tip

Permissions exist to protect your files and the operating system.

If you encounter an unfamiliar permission error, record the message and consult reliable documentation

before changing ownership or permissions.


8. Updating Ubuntu

Why should you update Ubuntu?

Software updates help keep your computer secure, reliable, and compatible with applications and hardware.

Updates can include security fixes, bug fixes, performance improvements, and other changes.

Keeping your system updated is an important part of maintaining a healthy computer.


What kinds of updates are available?

Ubuntu may provide updates for the operating system, installed applications, libraries, drivers, and other

software components.

Some updates focus on security, while others fix problems or improve functionality.

The updates available to you depend on your Ubuntu release and configured software sources.


Using Software Updater

Software Updater provides a graphical way to check for and install available system updates.

Open the application, follow the instructions, and review any information presented before confirming

the installation.

Allow the update process to complete and restart your computer if Ubuntu requests it.


Understanding package information updates

Ubuntu uses package information to find out which software versions are available from configured

repositories.

Refreshing this information does not automatically mean that every installed application has been upgraded.

Package information and installed software are related, but they are not the same thing.


Why might an update fail?

An update may fail because of an unstable internet connection, insufficient storage, an unavailable

repository, a package conflict, or another software installation already running.

If an error appears, record the message and investigate the specific cause instead of trying random commands.


Before installing updates

- Save your open documents and other work.

- Make sure the computer has a reliable internet connection when downloading updates.

- Check that sufficient storage space is available.

- Review any warnings or proposed software changes.

- Back up important personal files regularly.


Why should updates not be interrupted?

During an update, Ubuntu may replace or configure important software components.

Interrupting an update at the wrong time can leave a software operation incomplete and may require repair.

Unless the system has genuinely become unresponsive, allow an active update to finish.


What is an Ubuntu release?

An Ubuntu release is a particular version of the operating system.

Different releases have different software versions, support periods, and available features.

Some Ubuntu releases receive long-term support, while others have shorter support periods.

Check Ubuntu's official release information to learn about the support period for your installed version.


Helpful tip

Check for updates regularly and use Ubuntu's normal update tools whenever possible.

If your system repeatedly fails to update, write down the error message and consult the troubleshooting

section before attempting advanced package repairs.


9. Backing Up Your Files

What is a backup?

A backup is an additional copy of important information that can be used if the original files are lost,

damaged, deleted, or made unavailable.

Backups can protect personal documents, photographs, projects, and other information that would be

difficult or impossible to replace.


Why are backups important?

Computers and storage devices can fail. Files can also be deleted accidentally or affected by software

problems, theft, or other unexpected events.

A backup gives you another copy of your information so you have a better chance of recovering it.

Keeping only one copy of an important file leaves you vulnerable if that copy is lost.


What should you back up?

Important items may include:

- Documents and schoolwork.

- Photographs and videos.

- Programming projects and other personal files.

- Important downloads that are difficult to obtain again.

- Personal files used by applications, when appropriate.

Consider which files would be difficult to replace if your computer stopped working.


Using an external drive

You can copy important files to a suitable external hard drive or USB storage device.

Organize the copies so that you can find and restore them later.

After copying files, check that the copies exist and can be opened.

Use Ubuntu's safe-removal or eject option when available before disconnecting external storage.


Using backup software

Ubuntu-compatible backup applications can help you schedule backups and choose which files to protect.

Some tools can save backups to external storage or supported network locations.

Choose a reliable application, read its documentation, and make sure you understand where your backups

are stored.


Why should backups be stored separately?

If your only backup is stored on the same physical drive as your original files, a drive failure may affect

both copies.

Keeping a backup on a separate device or another suitable storage location can reduce this risk.

For especially important information, having more than one backup can provide additional protection.


How often should you back up?

The right schedule depends on how often your files change and how important they are.

Files that change frequently may need more regular backups than files that rarely change.

Choose a schedule that you can maintain consistently.


Test your backups

A backup is only useful if the files can be recovered when you need them.

Periodically open a few backed-up files and check that they work correctly.

Learn how to restore files before an emergency occurs.


Helpful tip

Make backups before major system changes, operating system upgrades, or other tasks that could affect

important information.

Keep external backup devices disconnected when you are not using them if appropriate, and store them

somewhere safe.


10. Customizing the Ubuntu Desktop

What is desktop customization?

Desktop customization allows you to change the appearance and behavior of your computer's interface.

You can adjust settings to make Ubuntu more comfortable to use, improve readability, and organize your

workspace according to your preferences.

The available customization options depend on your Ubuntu version and desktop environment.


Changing your wallpaper

Your wallpaper is the background image displayed on the desktop.

You can usually change it through Ubuntu's appearance settings or by selecting an image using the

appropriate desktop options.

Choose an image that you enjoy and make sure it does not make desktop icons difficult to see.


Changing the appearance

Ubuntu provides appearance settings that may let you choose between light and dark styles or adjust

other aspects of the desktop.

Some settings can also change accent colors or the appearance of supported applications.

Available choices depend on your installed desktop environment and Ubuntu version.


Adjusting display settings

Display settings let you adjust options such as screen resolution, display arrangement, scaling, and

orientation when supported by your hardware.

If you use more than one monitor, you may be able to choose how the screens are arranged and which

one acts as the primary display.

Choose settings that keep text readable and make applications comfortable to use.


Customizing keyboard shortcuts

Keyboard shortcuts help you perform tasks quickly without using the mouse for every action.

Ubuntu's Keyboard settings may let you review existing shortcuts and create or change certain shortcuts.

Before assigning a new combination, check whether another action already uses it.

For more information, visit the Keyboard Shortcuts section of TuxGuide.


Accessibility settings

Accessibility settings help make the computer easier to use for people with different needs and

preferences.

Depending on your Ubuntu version, these options may include larger text, screen magnification, visual

alerts, keyboard assistance, and other features.

Explore these settings to discover options that make your computer more comfortable to use.


What are GNOME extensions?

GNOME extensions can add features or change aspects of the GNOME desktop environment.

Some extensions add indicators, adjust the desktop layout, or provide additional controls.

Extensions may not work with every GNOME version, so check compatibility before installing one.

Use trusted sources and avoid installing extensions that request permissions you do not understand.


What are themes and icon packs?

Themes can change the appearance of desktop elements and supported applications.

Icon packs change the appearance of icons used by applications and parts of the desktop.

Some themes require additional tools or configuration and may not work with every Ubuntu release.

Before installing a theme, check its source, compatibility, installation instructions, and removal method.


Keeping your desktop comfortable and accessible

Use readable text sizes, suitable contrast, and a layout that makes important controls easy to find.

Avoid installing too many extensions or customization tools at once, because they can sometimes conflict

with each other or stop working after an update.

If a customization causes a problem, consult its documentation to learn how to disable or remove it safely.


Helpful tip

Start by exploring Ubuntu's built-in settings before installing additional themes or extensions.

You can make many useful changes without installing extra software.
