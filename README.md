## TuxGuide Project Code

**Hallo I Made TuxGuide, TuxGuide Is A Ubuntu Helper Which If You Are New To Ubuntu You Can Look At TuxGuide.**

*TuxGuide Has 4 Tabs And Those Are Troubleshooting, Shortcuts, Commands and Guides.*

# TuxGuide Features

*The Current Features TuxGuide Have Is Listed Down Below.*

- Guides Which Is A Guide For Complete Beginners.
- Troubleshooting Helps You Fix Whatever is Wrong With Your Computer.
- Shortcuts Shows The Shortcuts Ubuntu Features.
- Commands Shows Ubuntu's Terminal Commands.
